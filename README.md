### Projetos em Destaque

#### 1. Sistema de Cadastro de Pets (CLI)
Uma aplicação prática do que venho aprendendo no meu Hub de Estudos. Este sistema CLI (terminal) foi desenvolvido em **Java** e realiza o CRUD completo de pets e adotantes. O foco principal foi dominar a **lógica de manipulação de arquivos .txt** para persistência manual. A arquitetura foi estruturada seguindo os princípios de **DDD (Domain-Driven Design)**, **SOLID** e **Design Patterns**. Contém documentação detalhada com **Diagrama de Classes**, **PRDs** e **User Stories**.

 **[Ver Código e Documentação no GitHub](https://github.com/Kaua-Henrique1/sistema-cadastro-java)**

---

#### 2. Sistema de Adoção de Pets para ONG (Full Stack API & Web)
Aplicação Full Stack desenvolvida para gerenciar e otimizar o processo de adoção de pets em ONGs. O back-end consiste em uma API RESTful escalável construída em **Java 17** e **Spring Boot**, aplicando princípios **SOLID**, **DTOs** e **ModelMapper**, além de testes unitários com **JUnit 5** e documentação interativa via **Swagger / OpenAPI**. O front-end conta com uma interface web responsiva desenvolvida em **Angular (TypeScript, HTML5, CSS3)** modularizada em componentes. Todo o ambiente de banco de dados **PostgreSQL** é orquestrado e isolado utilizando **Docker** e **Docker Compose**.

 **[Ver Código e Documentação no GitHub](https://github.com/Kaua-Henrique1/sistema-adocao-pets-api)**
